2. PROJECT ARCHITECTURE & DEPLOYMENT FILES EXPLAINED
================================================================================
The following files are already created in your project root to enable seamless
cloud deployment on Render:

1. Procfile:
   - Tells Render what web server to start.
   - Content: "web: gunicorn fenix_it_mall.wsgi:application"
   - Gunicorn is a high-performance Python WSGI HTTP server for UNIX/Linux.

2. build.sh:
   - Bash script that runs automatically every time code is deployed.
   - Installs all dependencies from requirements.txt.
   - Compresses and organizes static files (CSS, JS, images) via collectstatic.
   - Applies database migrations (python manage.py migrate).
   - Initializes the default admin user (python manage.py init_admin).
   - Automatically seeds the initial catalog data (products, categories, etc.).

3. requirements.txt:
   - Contains all Python packages required to run the project:
     * Django (core framework)
     * Pillow (image handling for product thumbnails)
     * reportlab (PDF generation for invoices and reports)
     * python-barcode & qrcode (POS barcode & QR generation)
     * gunicorn (production WSGI web server)
     * whitenoise (high-speed static file serving)

4. fenix_it_mall/settings.py:
   - Configured with WhiteNoise middleware for instant CSS/JS loading.
   - Configured with CSRF_TRUSTED_ORIGINS to allow form submissions from Render.
   - Dynamic SECRET_KEY and DEBUG settings using environment variables.

5. render.yaml:
   - Blueprint configuration allowing Render to read your build parameters.

10. STEP 8: HOW TO UPDATE THE LIVE WEBSITE IN THE FUTURE (AUTOMATIC DEPLOY)
================================================================================
Because Render is connected directly to your GitHub repository, ANY future
updates are 100% AUTOMATIC!

Whenever you make any change to your code:

1. Edit your files locally in VS Code.
2. Open your terminal in VS Code and run:
     git add .
     git commit -m "Describe what changes you made"
     git push origin main

3. That is all!
   - Render will immediately detect your new commit on GitHub.
   - Render automatically pulls the new code, runs ./build.sh, and updates your
     live website with zero manual steps.
   - Your updates will go live within 1 to 2 minutes.

Manual Redeploy (Optional):
If you ever want to force a redeploy manually from the browser:
- Open your Render Dashboard -> Click "fenix-it-mall".
- Click "Manual Deploy" at the top right.
- Click "Deploy latest commit" or "Clear build cache & deploy".

11. FREQUENTLY ASKED QUESTIONS & TROUBLESHOOTING TIPS
================================================================================

Q1: Why does the first load take 30-40 seconds after being inactive?
A: Render's free tier automatically spins down (sleeps) web services after
   15 minutes of inactivity to conserve free server resources. As soon as
   someone visits your website link, Render wakes up the server automatically.
   All subsequent page loads are lightning fast.

Q2: How can I check server errors or logs if something goes wrong?
A: In your Render Dashboard, click on "fenix-it-mall" and navigate to the
   "Logs" tab on the left menu. All live requests, print statements, and errors
   appear in real-time.

Q3: Can I add my own custom domain?
A: Yes! Under "Settings" -> "Custom Domains" in Render, you can connect your
   own domain (e.g., www.fenixitmall.com) for free with automatic SSL certificates.

Q4: What if I forget the admin password on the live site?
A: In your Render Dashboard, go to the "Shell" tab on the left menu, click
   "Connect", and run:
   python manage.py createsuperuser
   Follow the prompts to create a new admin account directly on the live server.
